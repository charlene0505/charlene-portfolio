This is a placeholder article so the Writing section has something to render.

To add a real post, drop a new `.mdx` file into `src/content/writing/`, give it
`title`, `date`, and `excerpt` frontmatter like this one, then write the body
below the `---` in plain Markdown. It'll show up automatically — no other file
needs to change.

You can delete this file once you have real posts.
